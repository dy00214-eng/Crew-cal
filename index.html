    기존 일정 처리

    스케줄 화면을 캡처해서 올리면 날짜 · 코드 · 구간 · 출발/도착 시각을 읽어옵니다. 달력 형태든 목록 형태든 됩니다. 읽은 결과는 바로 반영하지 않고 텍스트 미리보기로 넘겨서 확인·수정한 뒤 반영합니다.

    이미지를 끌어다 놓거나 클릭해서 선택하세요

    PNG · JPG · WEBP · GIF / 5MB 이하

    스크린샷의 글자를 옮기는 두 가지 방법

    1. 사진 앱에서 글자 복사 (아이폰)
      사진 앱에서 스케줄 스크린샷을 열고 오른쪽 아래 텍스트 인식 버튼을 누른 뒤, 스케줄 부분을 선택해 복사하세요. 그대로 텍스트 붙여넣기 탭에 붙여넣으면 됩니다. 한 줄에 하루씩 적힌 목록형 스케줄에 잘 맞습니다.
    2. Claude 대화창에 보내기
      스크린샷을 이 대화에 올리고 “크루캘에 넣을 텍스트로 바꿔줘” 라고 하세요. 받은 텍스트를 텍스트 붙여넣기 탭에 넣으면 됩니다. 달력 모양 스케줄도 됩니다.

    직접 서버를 운영할 때만 쓰는 설정

    보통은 비워두면 됩니다. 이 칸은 이미지 인식용 서버를 직접 만들어 돌릴 때 그 주소를 적는 곳이라, 넣을 주소가 없다면 그냥 두세요. 브라우저에 API 키를 두면 그대로 노출되므로 키는 서버에 두고, 여기에는 서버 주소만 넣습니다. 서버는 { image_base64, media_type, prompt } 를 받아 { text } 또는 { entries } 로 응답하면 됩니다.

    기억한 편명 0개

    구간이나 시각을 한 번 넣은 편명은 기억해 두었다가, 다음에 코드만 들어오면 그대로 채웁니다. 크루넷 월간 화면처럼 시각이 없는 스케줄에도 시각이 붙습니다.
