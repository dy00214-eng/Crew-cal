# Crew-cal

승무원 스케줄을 달력으로 관리하는 정적 웹 앱. 빌드 도구나 의존성 없이 `index.html` 만 열면 동작한다.

## 입력 방식 3가지

### 1. 날짜별 입력
날짜 · 코드 · 구간 · 시각 · 메모를 하나씩 입력한다. 달력에서 날짜를 누르면 그 날짜가 바로 폼에 잡히고,
아래에 해당 날짜의 일정 목록이 나와 개별 삭제도 가능하다.

### 2. 텍스트 붙여넣기
크루넷에서 복사한 스케줄 텍스트를 그대로 붙여넣으면 날짜와 코드를 파싱해 **미리보기**로 보여주고,
확인을 눌러야 달력에 반영된다. 반영 시 해당 날짜의 기존 일정을 덮어쓸지, 이어 붙일지 고를 수 있다.

파서(`src/parser.js`)가 받아들이는 형태:

| 종류 | 예 |
| --- | --- |
| 연-월-일 | `2026-09-06`, `2026.09.06`, `2026/09/06`, `20260906` |
| 월-일 (연도는 기준 연·월로 보정) | `09/06`, `9-6` |
| 한글 | `2026년 9월 6일`, `9월 6일`, `6일` |
| 영문 월 | `06SEP26`, `07 SEP`, `SEP08` |
| 줄 앞의 일자 | `01\tKE0035` |
| 날짜 범위 | `2026-09-10 ~ 2026-09-12 VAC` |
| 날짜 줄 + 코드 줄 | 날짜만 있는 줄 다음의 코드 줄들이 그 날짜에 붙는다 |

- 코드: 항공편(`KE0035`, `KE 0035`, `KE-035`)과 근무 코드(`LO`, `ATDO`, `STBY`, `DO`, `VAC`, `GT` …)
- 부가 정보: 구간 `ICN/JFK`, 시각 `1030-1420` / `09:30-14:20` 은 앞의 항공편에 붙는다
- 구분자는 공백 · 탭 · 쉼표 · 파이프 무엇이든 되고, 요일 표기 `(일)` `[MON]` 과 표 머리글은 무시한다
- 사전에 없는 코드는 버리지 않고 **미확인**으로 표시한 뒤 미리보기에서 기본 해제 상태로 둔다 (체크하면 그대로 반영)
- 날짜를 못 찾은 줄은 경고 목록에 남긴다

근무 코드 사전은 `src/codes.js` 에 있다. 코드를 추가하려면 이 파일에 한 줄 넣으면 달력 색과 라벨까지 함께 붙는다.

### 3. 스크린샷 업로드 (연동 자리)
이미지 업로드 · 미리보기 · 유효성 검사 · 설정 UI까지는 동작하고, **실제 인식은 다음 단계에서 Claude API 를 붙일 예정**이다.
`src/vision.js` 가 그 자리를 잡고 있다.

브라우저에 API 키를 두면 그대로 노출되므로, 키는 서버에 두고 앱에는 서버 엔드포인트 주소만 넣는다
(스크린샷 탭 → "이미지 인식 API 연동 설정").

서버가 지켜야 할 규약:

```
POST {endpoint}
요청  { image_base64, media_type, prompt, model, hint: { year, month } }
응답  { text }     // "YYYY-MM-DD<탭>코드 …" 형식 → 텍스트 파서로 넘어감
   또는 { entries: [{ date, code, route?, start?, end? }] }
```

응답이 오면 텍스트 붙여넣기와 똑같이 미리보기 → 확인 절차를 거친다.
서버에서 Claude Messages API 로 넘길 요청 본문은 `vision.buildClaudeRequest()` 가, 추출 프롬프트는
`vision.EXTRACTION_PROMPT` 가 그대로 들고 있다.

## 저장
모든 일정은 브라우저 `localStorage`(`crew-cal.schedule.v1`)에 저장된다. 서버로 나가는 데이터는 없다.
하단의 백업 내보내기 / 불러오기로 JSON 파일 왕복이 가능하다.

## 실행

```bash
# 그냥 index.html 을 브라우저로 열어도 된다
python3 -m http.server 8000   # http://localhost:8000
```

## 테스트

```bash
npm test        # node --test, 의존성 없음
```

## 구조

```
index.html        화면 구조
styles.css        스타일
src/codes.js      근무 코드 사전 (라벨·분류)
src/parser.js     텍스트 → 날짜+코드 파서
src/store.js      localStorage 일정 저장소
src/calendar.js   월간 달력 렌더러
src/vision.js     스크린샷 인식 어댑터 (Claude API 연동 자리)
src/app.js        화면 조립
test/             파서·저장소 테스트
```
