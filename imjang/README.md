# 임장 노트

관심 매물을 저장해두고, 현장(임장)에 가서 기록하고, 여러 매물을 비교해 결정하는 개인용 PWA.

**설계 기준이 되는 장면:** 현장에 서서 한 손으로 폰을 들고, 지하나 엘리베이터 안이라 인터넷이 끊긴 상태에서
방금 본 것을 기록하는 순간. 모든 판단은 이 장면을 기준으로 했다.

- 서버 없음 · 계정 없음 · 로그인 없음. 데이터는 전부 이 기기의 IndexedDB 안에만 있다
- 읽기 경로에 네트워크가 끼어들지 않는다. 앱을 열 때 로딩 스피너가 뜨지 않는다
- 네트워크를 쓰는 곳은 **매물 담기(파싱)** 와 **실거래가 갱신** 둘뿐이고, 둘 다 직접 누를 때만 움직인다
- 대상 매물 유형은 아파트 / 단독주택 / 고급빌라 세 가지

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm run build      # dist/ 로 정적 빌드 (PWA 포함)
npm run preview    # 빌드 결과 확인
npm test           # 순수 로직 테스트 (vitest)
npm run typecheck  # 타입 검사
npm run icons      # public/icons/*.png 다시 생성
```

빌드 결과 `dist/` 는 그대로 정적 호스팅(Vercel / Netlify / GitHub Pages)에 올리면 된다.
`base: './'` 와 HashRouter 를 쓰기 때문에 하위 경로에 올려도 그대로 동작한다.

### 실거래가 API 키

```bash
cp .env.example .env
# VITE_MOLIT_KEY 에 공공데이터포털에서 발급받은 키를 넣는다
```

`.env` 는 커밋하지 않는다. 키가 없으면 실거래가 조회 버튼만 꺼지고, 나머지 기능은 전부 그대로 동작한다.

## 화면

| 경로 | 화면 | 하는 일 |
| --- | --- | --- |
| `#/` | 목록 | 행 + 구분선. 정렬(최근·가격·평점), 필터(상태·유형), 비교 선택 |
| `#/new` | 매물 담기 | 직접 입력 |
| `#/share` | 공유로 담기 | Web Share Target 으로 받은 URL·제목·본문을 파싱 |
| `#/p/:id` | 상세 | 사진·기본정보·메모·체크리스트·서류확인·실거래가 |
| `#/map` | 지도 | 담아 둔 매물을 가격 말풍선으로. 구역을 저장해 두면 오프라인에서도 뜬다 |
| `#/compare` | 비교 | 2~3개를 세로 표로 나란히. **결정은 여기서 난다** |
| `#/settings` | 설정 | 저장 용량, 백업 내보내기/가져오기 |

## 구조

```
src/
├── db/              데이터 모델(types.ts) · Dexie 스키마(db.ts) · 읽기·쓰기(repo.ts)
├── config/
│   └── checklists.ts  체크리스트 정의. UI 는 이걸 순회해서 그린다 (하드코딩 없음)
├── parsers/
│   └── naver.ts       네이버 부동산 파싱. 깨지면 이 파일만 고친다
├── api/
│   └── molit.ts       국토교통부 실거래가
├── lib/             포맷 · 사진 처리 · 백업 · 저장공간 · 훅
├── components/      공용 조각 (행 썸네일, 평점, 폼, 차트)
├── routes/          화면
└── styles/          tokens.css (색·크기) + app.css
```

### 데이터 모델

`properties` · `photos` · `priceRecords` 세 테이블. `properties` 는 `status`, `type`, `updatedAt`, `price` 에 인덱스가 있다.

스펙의 `complexKey`(법정동코드+단지명)는 매물에 `lawdCd` + `complexName` 두 조각으로 들고 있다가
`complexKeyOf()` 로 합쳐 쓴다. 실거래가를 부를 때 두 값이 각각 필요하기 때문이다.

### 사진

기기 용량을 날려먹는 지점이라 저장 전에 반드시 처리한다.

1. `createImageBitmap` → `OffscreenCanvas` 로 리사이즈 (없는 브라우저는 `<canvas>` 로 내려간다)
2. 긴 변 **1600px, JPEG 0.8** 로 저장하고 원본은 버린다
3. 목록용 **200px 썸네일** 을 따로 만들어 함께 저장한다
4. 목록 화면은 썸네일만 읽는다 (`thumbsFor`). 원본 Blob 은 상세에서만 연다
5. `URL.createObjectURL` 은 `useObjectUrl` / `useObjectUrls` 훅 안에서만 만들고, 언마운트 때 반드시 revoke 한다

실측: 2400×1800 PNG(232KB) → 1600×1200 JPEG(27KB) + 200×150 썸네일(2KB).

### 파싱이 깨질 때

네이버가 페이지 구조를 바꾸면 파싱은 반드시 깨진다. 그래서 `src/parsers/naver.ts` 의 함수는
**예외를 밖으로 던지지 않는다.** 실패하면 `warnings` 에 이유를 담아 돌려주고, 화면은 조용히
수동 입력 폼으로 넘어가되 URL 과 제목은 채워둔 상태로 둔다.

읽는 순서는 ① 공유받은 제목·본문 → ② (부족하면) 링크 1회 fetch 후 og 메타/JSON 긁기.
요청은 건당 1회, 사용자 액션이 있을 때만. 자동 재시도·백그라운드 갱신은 없다.

> 브라우저에서 네이버 페이지를 직접 fetch 하면 CORS 로 막히는 경우가 많다. 그때도 앱은 멈추지 않고
> 공유 텍스트에서 읽어낸 값 + 링크만 채운 폼으로 넘어간다. 실제로 공유 본문만으로 가격·면적·층·향까지 대부분 채워진다.

### 실거래가

공공데이터포털 국토교통부 실거래가 API 를 월 단위로 훑어 `priceRecords` 에 캐시한다.
한 번 받아두면 오프라인에서도 그래프가 보인다.

아파트는 잘 나오지만 **단독주택·빌라는 데이터가 희박하다.** 결과가 없으면
"이 지역 실거래 사례가 적습니다" 라고 분명히 알린다 — 빌라에서는 그 사실 자체가 환금성 판단 재료다.

브라우저에서 `apis.data.go.kr` 가 CORS 로 막히면 `.env` 의 `VITE_MOLIT_BASE` 를 직접 띄운 프록시 주소로 바꾼다.

### 지도

네이버처럼 **모든 매물을 지도에서 탐색**하는 화면이 아니다. **내가 담은 매물만** 가격 말풍선으로 얹는다.
매물이 추가·수정되면 말풍선은 곧바로 다시 그려진다 (IndexedDB 를 그대로 읽으므로 오프라인에서도 같다).

- 타일 읽기는 서비스워커가 `CacheFirst` 로 맡는다 — **한 번 본 구역은 오프라인에서도 그대로 뜬다**
- 넓게 쓰려면 지도에서 **"이 지역 저장"** 을 누른다. 지금 보이는 범위를 현재 줌 + 한 단계까지,
  가운데부터 최대 400칸 받아 둔다. 자동으로 긁어오지 않고, 동시 요청은 2개로 묶는다
- 위치는 **지도를 눌러 핀으로** 정한다. 주소 자동 변환(지오코딩)은 온라인·API 키가 필요해서 쓰지 않았다
- 저장해 둔 타일 수와 비우기는 설정 화면에 있다. 사진 넣을 자리가 모자라면 여기부터 비우면 된다

#### 타일 출처 고르기

| 설정 | 쓰는 것 | 키 |
| --- | --- | --- |
| 아무것도 안 넣음 | OpenStreetMap | 필요 없음 |
| `VITE_VWORLD_KEY` | **VWorld (국토교통부)** — 한국 지명·건물·도로명이 제대로 나온다 | 무료, 발급 필요 |
| `VITE_TILE_URL` | 직접 지정한 타일 서버 (위 둘보다 우선) | 제공자에 따라 |

VWorld 를 쓰려면 [vworld.kr](https://www.vworld.kr) 에서 인증키를 발급받아 `.env` 에 넣는다.
발급할 때 **이 앱을 올릴 도메인을 등록**해야 한다.

```bash
VITE_VWORLD_KEY=발급받은-키
VITE_VWORLD_LAYER=Base        # Base / gray / midnight / Satellite / Hybrid
```

VWorld 의 WMTS 경로는 `.../{z}/{y}/{x}.png` 로 **x 와 y 가 OSM 과 뒤집혀 있다.**
`resolveTileSource()` 가 그 순서로 템플릿을 만들고, 테스트가 그 순서를 고정하고 있다.

> 웹 지도는 어느 제공자든 키가 클라이언트 번들에 박힌다. 그래서 VWorld 도 키 자체가 아니라
> **발급 시 등록한 도메인**이 보호 장치다. 개인 기기 하나에서 쓰는 앱이라 실질적인 문제는 없지만,
> 키를 공개 저장소에 커밋하지는 않는다 (`.env` 는 `.gitignore` 에 있다).

> OSM 공개 타일 서버는 대량 선다운로드를 권장하지 않는다. 개인용 한 명이 임장 갈 동네 하나를
> 저장하는 정도를 전제로 상한(400칸)과 동시 요청 수(2개)를 걸어 뒀다. 더 넓게 쓸 거라면
> 위 설정으로 자체 타일 서버나 유료 제공자를 쓰는 게 맞다.
>
> 서비스워커 캐시 규칙은 `vite.config.ts` 의 `runtimeCaching` 에 있다. 타일은 다른 오리진에서 오므로
> 정규식이 **URL 맨 앞부터** 맞아야 워크박스가 route 로 받아 준다 (`^https?://…`). 이걸 놓치면
> 오프라인에서 타일이 전혀 안 뜬다.

### 백업

서버가 없으므로 기기를 잃으면 전부 사라진다. 설정 화면에서 ZIP 하나로 내보내고 같은 ZIP 으로 복원한다.
ZIP 안에는 `data.json`(매물·실거래가·사진 메타)과 `photos/<id>.jpg`(원본+썸네일)가 들어간다.
파일 이름은 ASCII 로 둔다 — 크로미움이 한글 이름을 blob 다운로드에서 통째로 버려 확장자까지 잃기 때문이다.

## 디자인

컨셉은 **현장 수첩(field notebook)**. 매물을 예쁘게 보여주는 곳이 아니라 밖에서 서서 판단을 적어 넣는 도구다.

- 색은 `src/styles/tokens.css` 여섯 개가 전부. 강조색은 `--stamp` 하나뿐이다
- 그라디언트·그림자를 쓰지 않는다. 깊이는 선(rule)과 여백으로 만든다
- 카드가 아니라 **행 + 구분선**. 한 화면에 더 많은 매물이 들어와야 비교가 쉽다
- 숫자에는 `tabular-nums`. 목록에서 자릿수가 흔들리면 비교가 안 된다
- 본문 최소 16px, 터치 타깃 최소 44px
- 정렬·필터는 접어 둔다. 목록이 화면 위쪽부터 시작해야 한다

글꼴은 Pretendard 가 기기에 있으면 쓰고, 없으면 시스템 한글 글꼴로 내려간다.
웹폰트를 프리캐시하면 오프라인 셸이 2MB 넘게 무거워져서 그렇게 하지 않았다.
자체 호스팅하려면 `public/fonts/` 에 woff2 를 넣고 `tokens.css` 의 `--font` 앞에 `@font-face` 를 더하면 된다.

## 확인한 것

- 오프라인(네트워크 차단)에서 앱 실행 → 목록 → 상세 → 메모 작성·저장 후 새로고침까지 그대로 남는다
- 매물 100건 + 사진 300장에서 목록 표시 105ms, 스크롤 프레임 중앙값 16.7ms (60fps)
- 백업 내보내기 → DB 삭제 → 가져오기로 매물·사진이 그대로 돌아온다
- 네이버 파싱: 공유 텍스트에서 제목·주소·가격·면적·층·향을 뽑고, 실패해도 앱의 다른 기능은 전부 정상 동작한다
- 지도: "이 지역 저장" 후 **타일 서버를 죽여도** 저장한 구역이 그대로 뜨고, 타일 캐시를 비우면 0칸이 된다
  (오프라인 지도가 캐시 덕분임을 확인). 오프라인에서 매물을 담고 핀을 찍으면 지도에 곧바로 반영된다
- VWorld 의 `{z}/{y}/{x}` 경로 모양으로도 지도 렌더링·타일 캐시·오프라인이 모두 동작한다
  (실제 키 대신 같은 경로 모양의 로컬 서버로 확인)

## 아직 안 한 것

- 실거래가 API 는 실제 키로 호출해보지 않았다 (응답 XML 파싱은 테스트로 고정해 뒀다)
- VWorld 도 실제 인증키로는 호출해보지 않았다. 개발 환경에서 `api.vworld.kr` 로 나가는 길이 막혀 있어
  경로 모양·캐시 동작만 같은 형태의 로컬 서버로 확인했다. 키를 발급받아 처음 켤 때
  타일이 안 뜨면 ① 도메인 등록 ② 레이어 이름 ③ 일일 호출 제한을 순서대로 보면 된다
- Web Share Target 은 안드로이드 실기기에 설치해 **공유 메뉴에 뜨는지** 확인이 필요하다.
  앱 쪽 처리(`/share?…` → 서비스워커 폴백 → `#/share?…` → 폼 채우기)는 온라인·오프라인 모두 확인했다
